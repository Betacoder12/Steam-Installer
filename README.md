# Steam Installer No Admin Perms or Command Prompt
Wanted Steam even though you have no admin or command prompt? You can with these vbs scripts (you double click them to run them)

## IMPORTANT
1. STEAM WEB HELPER DOES NOT SHUT DOWN AFTER CLOSING AND REOPENS STEAM IF YOU TRY TO CLOSE IT IN TASK MANAGER!!!
2. You cannot play any games with anticheat, so some online games may not work.

## Step 1
Download MSYS2 from https://www.msys2.org/ and go through the setup process

## Step 2
Got to code, HTTPS, and download zip. Unzip it wherever you want.

## Step 3
Double click the steam_installer.vbs script, go through the setup process with the install folder to be either C:/msys64/home/<\your account name>\/steam/steaminstall or wherever you want other than program files (this will make all steam and game start scripts not work).

## Step 4
Double click the run_steam.vbs script, click ignore and cancel on any pop-ups, sign in, download the games you want. 

## If Games are NOT LAUNCHING in Steam
If your games are not launching in steam on your device, use the game_launcher_creator.vbs script. It will create launch scripts for your games. If the game tab pop-ups then goes away, click play in steam for the game.
