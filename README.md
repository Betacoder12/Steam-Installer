# Steam Installer No Admin Perms or Command Prompt
Wanted Steam even though you have no admin or command prompt? You can with these vbs scripts (you double click them to run them)

## Step 1
Download MSYS2 from this link. Go through the setup process

## Step 2
Got to code, HTTPS, and download zip. Unzip it wherever you want.

## Step 3
Double click the steam_installer script, go through the setup process with the install folder to be either C:/msys64/home/<\your account name>\/steam/steaminstall or wherever you want other than program files (this will make all steam and game start scripts not work).

## Step 4
Double click the run_steam installer, sign in, download games.
